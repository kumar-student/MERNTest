## MongoDB – Installation, Configuration, CRUD operations
### a. Installation and Configuration of MongoDB Atlas (Cloud Database) and Connection Using MongoDB Compass

**Aim**:
To create a **MongoDB Atlas cloud database deployment**, configure database and network access, and connect to the database using **MongoDB Compass**. Optionally, verify the connection through a Node.js application.

**Objectives**:

After completing this experiment, the student will be able to:

- Create a MongoDB Atlas account.
- Create a MongoDB Atlas project and free deployment.
- Configure database authentication.
- Configure network access.
- Connect to the Atlas deployment using MongoDB Compass.
- Create a database and collection.
- Insert and view documents.
- (Optional) Connect to Atlas from a Node.js application.

**Software/Tools Required**:
- Internet Connection
- MongoDB Atlas Account
- MongoDB Compass (Latest Version)
- Node.js (Optional)
- MongoDB Node.js Driver (Optional)

**Theory**:

**MongoDB** is a NoSQL document-oriented database that stores data in flexible JSON-like documents called **BSON (Binary JSON)** documents.

**MongoDB Atlas** is MongoDB's fully managed cloud database service that allows users to deploy, manage, and scale MongoDB databases without installing database server software locally.

**MongoDB Compass** is the official graphical user interface (GUI) that enables users to connect to MongoDB databases, create databases and collections, insert documents, and execute queries.

**Procedure (Step-by-Step)**:

**Step 1**: Create a MongoDB Atlas Account
- Open a web browser.
- Visit **[https://www.mongodb.com/cloud/atlas](https://www.mongodb.com/cloud/atlas)**.
- Click **Try Free** or **Get Started**.
- Sign up using your email address or a Google/GitHub account.
- Verify your email address if prompted.
- Sign in to MongoDB Atlas.

**Step 2**: Create an Atlas Project

1. After signing in, click **New Project** if no project exists.
2. Enter a project name.

Example:
```
DBMS_Lab
```

3. Click **Create Project**.

**Step 3**: Create a Free Atlas Deployment

1. Inside the project, click **Build a Database** or **Create Deployment**.
2. Select the **Free (M0)** deployment.
3. Choose a cloud provider.

Example:

- AWS
- Google Cloud
- Microsoft Azure

4. Select the nearest available region.

Example:
```
AWS – Mumbai (ap-south-1)
```

5. Leave the default deployment settings unless instructed otherwise.
6. Click **Create Deployment**.

Wait several minutes while Atlas provisions the deployment.

**Step 4**: Create a Database User

1. During deployment setup (or later through **Database Access**), create a database user.
2. Select **Password Authentication**.
3. Enter:

Example:
```
Username:
student

Password:
Student@123
```

_(Use a strong password in actual practice.)_

4. Assign the role:
```
Atlas Admin
```

or

```
Read and Write to Any Database
```

5. Click **Create User**.

**Note:** Save the username and password securely. They are required for future connections.

**Step 5**: Configure Network Access

1. Navigate to **Network Access**.
2. Click **Add IP Address**.
3. For laboratory purposes, select:

```
Allow Access from Anywhere
```

which adds

```
0.0.0.0/0
```

4. Save the settings.

> **Security Note:** Using `0.0.0.0/0` permits connections from any IP address and is suitable only for learning or testing. In production environments, restrict access to trusted IP addresses.

**Step 6**: Obtain the Connection String
1. Open your Atlas deployment.
2. Click **Connect**.
3. Choose **MongoDB Compass**.
4. Copy the connection string generated by Atlas.

It will resemble:

```
mongodb+srv://<username>:<password>@cluster-name.xxxxx.mongodb.net/?retryWrites=true&w=majority
```

5. Replace:

```
<username>
```

with your database username.

6. Replace:

```
<password>
```

with your database password.

**Important:** Copy the complete connection string generated by Atlas. Do not manually type or shorten it.

**Step 7**: Connect Using MongoDB Compass

1. Open **MongoDB Compass**.
2. Paste the connection string into the connection field.
3. Click **Connect**.
4. Wait until Compass establishes the connection.

If successful, the Atlas deployment and its databases will appear in the left navigation panel.

**Step 8**: Create a Database

1. Click **Create Database**.
2. Enter:

```
Database Name:
StudentDB

Collection Name:
Students
```

3. Click **Create Database**.

**Step 9**: Insert a Sample Document

1. Open the **Students** collection.
2. Click **Insert Document**.
3. Insert the following document:

```
{
  "rollNo": 101,
  "name": "Rahul Sharma",
  "department": "Computer Science",
  "semester": 5,
  "cgpa": 8.5
}
```

4. Click **Insert**.

The document should now appear in the collection.

**Step 10**: Verify the Connection

Verify that:

- Atlas deployment is connected.
- Database **StudentDB** exists.
- Collection **Students** exists.
- The inserted document is visible.
- No connection errors are reported.

Successful completion confirms that MongoDB Atlas and MongoDB Compass are configured correctly.

**Connect Using Node.js**

Install Required Packages

```
npm install mongodb
```

Create a JavaScript File

`index.js`
```js

const { MongoClient, ServerApiVersion } = require('mongodb');
const uri = "mongodb+srv://<username>:<password>@<cluster-name>.xxxxxxx.mongodb.net/?appName=<appname>";

// Create a MongoClient with a MongoClientOptions object to set the Stable API version
const client = new MongoClient(uri, {
  serverApi: {
    version: ServerApiVersion.v1,
    strict: true,
    deprecationErrors: true,
  }
});

async function run() {
	try {
		// Connect the client to the server	(optional starting in v4.7)
		await client.connect();
		// Send a ping to confirm a successful connection
		await client.db("admin").command({ ping: 1 });
		console.log("Pinged your deployment. You successfully connected to MongoDB!");
	} finally {
		// Ensures that the client will close when you finish/error
		await client.close();
	}
}
run().catch(console.dir);
```

Replace:

- `<username>`
- `<password>`
- `cluster-name.xxxxx.mongodb.net`

with the values provided by MongoDB Atlas.

Expected Output

```
Connected successfully to MongoDB Atlas
```

**Result**:

MongoDB Atlas was successfully configured, network and database access were established, MongoDB Compass connected successfully to the Atlas deployment, and a sample database, collection, and document were created and verified. Optionally, the Atlas deployment was accessed successfully using a Node.js application.

### b. Perform CRUD (Create, Read, Update, Delete) Operations on MongoDB Documents Using MongoDB Shell

**Aim**

To perform CRUD (Create, Read, Update, Delete) operations on documents stored in a MongoDB collection using the MongoDB Shell (`mongosh`) and the recommended MongoDB CRUD methods.

**Objectives**

After completing this experiment, the student will be able to:
- Create a MongoDB database and collection.
- Insert one or more documents into a collection.
- Retrieve documents using various `find()` queries.
- Update existing documents using update operators.
- Delete documents from a collection.
- Understand the purpose of each CRUD operation.
- Distinguish between deprecated and recommended MongoDB methods.

**Software/Tools Required**

- MongoDB Atlas (Cloud Database) configured from the previous experiment **or** MongoDB Community Server
- [MongoDB Shell](https://www.mongodb.com/try/download/shell) (`mongosh`)
- MongoDB Compass (Optional - for verification)
- Internet connection (if using Atlas)

**Prerequisites**

Before performing this experiment, ensure that:
- A MongoDB Atlas deployment (or local MongoDB server) is running.
- A database user has been created.
- Network access is configured (for Atlas).
- MongoDB Shell (`mongosh`) is installed.
- You can successfully connect to your MongoDB database.

**Theory**

MongoDB is a **NoSQL document-oriented database** that stores data in **BSON (Binary JSON)** documents.

CRUD represents the four basic database operations:

| Operation | Purpose                   | MongoDB Method                |
| --------- | ------------------------- | ----------------------------- |
| Create    | Add new documents         | `insertOne()`, `insertMany()` |
| Read      | Retrieve documents        | `find()`, `findOne()`         |
| Update    | Modify existing documents | `updateOne()`, `updateMany()` |
| Delete    | Remove documents          | `deleteOne()`, `deleteMany()` |

> **Note:** Earlier MongoDB versions supported methods such as `insert()`, `update()`, and `remove()`. These methods are deprecated and should not be used in new applications. Current MongoDB versions (including MongoDB 8.x in 2026) recommend using `insertOne()`, `insertMany()`, `updateOne()`, `updateMany()`, `deleteOne()`, and `deleteMany()`.

After connecting to MongoDB, type each command directly at the `mongosh` prompt.

Example:

```text
PS C:\Users\Student> mongosh
Current Mongosh Log ID: ...
Connecting to: mongodb+srv://...
Atlas atlas-xxxxx-shard-0 [primary] test>
```

>Note: All commands in this experiment are executed at the `mongosh` prompt.

**Procedure**:

**Step 1**: Connect to MongoDB

Open Command Prompt, Terminal, or PowerShell and start MongoDB Shell.

If using MongoDB Atlas:

```bash
mongosh "your-atlas-connection-string"
```

Example:

```bash
mongosh "mongodb+srv://student:password@cluster0.xxxxx.mongodb.net/"
```

If using a local MongoDB server:

```bash
mongosh
```

After connecting successfully, the MongoDB Shell prompt appears.

**Step 2**: Create (or Switch to) the Database

Execute:

```javascript
use collegeDB
```

Expected output:

```text
switched to db collegeDB
```

> **Note:** MongoDB creates the database only when the first document is inserted.

**Step 3**: Create a Collection

Create the collection:

```javascript
db.createCollection("students")
```

Expected output:

```javascript
{ ok: 1 }
```

Verify the collection:

```javascript
show collections
```

Expected output:

```text
students
```

**Step 4**: Insert Documents (Create Operation)

Insert multiple student records.

```javascript
db.students.insertMany([
	{
		rollNo: 101,
		name: "Rahul",
		age: 21,
		course: "B.Tech"
	},
	{
		rollNo: 102,
		name: "Priya",
		age: 22,
		course: "BCA"
	},
	{
		rollNo: 103,
		name: "Amit",
		age: 20,
		course: "B.Sc"
	}
])
```

Expected output:

```javascript
{
	acknowledged: true,
	insertedIds: {
		'0': ObjectId("..."),
		'1': ObjectId("..."),
		'2': ObjectId("...")
	}
}
```

**Step 5**: Retrieve Documents (Read Operation)

Display all documents.

```javascript
db.students.find()
```

To display documents in a more readable format:

```javascript
db.students.find().pretty()
```

> **Note:** The `.pretty()` helper is still available in `mongosh` for interactive readability, though it is a shell convenience rather than a database operation.

**Step 6**: Retrieve Specific Documents

Find students enrolled in BCA.

```javascript
db.students.find(
    { course: "BCA" }
)
```

Find only student names.

```javascript
db.students.find(
    {},
    {
        name: 1,
        _id: 0
    }
)
```

This demonstrates filtering and field projection.

**Step 7**: Update a Document (Update Operation)

Update Rahul's course.

```javascript
db.students.updateOne(
    {
        name: "Rahul"
    },
    {
        $set: {
            course: "M.Tech"
        }
    }
)
```

Expected output:

```javascript
{
  acknowledged: true,
  matchedCount: 1,
  modifiedCount: 1
}
```

Verify the update.

```javascript
db.students.find(
    {
        name: "Rahul"
    }
)
```

**Step 8**: Delete a Document (Delete Operation)

Delete Amit's record.

```javascript
db.students.deleteOne(
    {
        name: "Amit"
    }
)
```

Expected output:

```javascript
{
  acknowledged: true,
  deletedCount: 1
}
```

**Step 9**: Display Remaining Documents

Execute:

```javascript
db.students.find().pretty()
```

Expected output:

```javascript
[
	{
		"_id": ObjectId("..."),
		"rollNo": 101,
		"name": "Rahul",
		"age": 21,
		"course": "M.Tech"
	},
	{
		"_id": ObjectId("..."),
		"rollNo": 102,
		"name": "Priya",
		"age": 22,
		"course": "BCA"
	}
]
```

**Step 10**: Verify the CRUD Operations

Confirm that:
- Database **collegeDB** exists.
- Collection **students** exists.
- Three documents were inserted.
- Rahul's course was updated successfully.
- Amit's document was deleted.
- Two documents remain in the collection.

**Result**

CRUD operations were successfully performed on the **students** collection. Documents were inserted, retrieved, updated, and deleted using the recommended MongoDB CRUD methods in MongoDB Shell.
